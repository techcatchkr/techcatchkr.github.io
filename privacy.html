개인정보처리방침

시행일: 2026년 10월 17일

techcatch YouTube 업로드 도구(이하 "이 도구")는 YouTube 채널 techcatch 운영자 본인만 사용하는 개인용 프로그램입니다.

1. 접근하는 정보

운영자가 Google 계정으로 허락한 범위에서 아래 정보에만 접근합니다.

  • 운영자 YouTube 채널의 기본 정보(채널 이름, ID, 통계)
  • 운영자 채널의 조회수·시청시간·좋아요 등 YouTube 분석 통계
  • 운영자가 업로드를 지시한 영상 파일과 제목·설명

2. 이용 목적

운영자 본인 채널에 영상을 올리고, 채널 성과를 확인하는 데에만 사용합니다.

3. 보관과 보호

Google 인증 정보는 운영자 PC에만 Windows 암호화 저장소(DPAPI)로 보관하며, 외부 서버로 보내지 않습니다. 조회한 통계는 운영자 PC에만 저장합니다.

4. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 광고나 분석 목적으로 사용하지 않습니다.

5. Google 정책 준수

이 도구의 Google API 정보 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받는 YouTube API 서비스를 사용합니다.

6. 접근 철회

운영자는 언제든 Google 계정 권한 페이지에서 이 도구의 접근을 철회할 수 있으며, 그러면 PC에 저장된 인증 정보도 더 이상 쓸 수 없습니다.
